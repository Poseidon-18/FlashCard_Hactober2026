About F&Q Generator

F&Q Generator (Afterparty Edition) is an AI-powered study tool built for Hacktoberfest 2026 / Infinity AI Forge Hackathon (Challenge 06).

Key Features:

  • Instant PDF & text note parsing in browser via PDF.js
  • Gemma 4 model integration (gemma-4-26b-a4b-it)
  • 3D flippable flashcards with spaced repetition rating
  • Interactive practice quiz with explanations
  • Anki CSV & JSON schema exports
