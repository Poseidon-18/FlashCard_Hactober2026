About F&Q Generator

F&Q Generator is an AI-powered study tool built for Hacktoberfest 2026 as part of the Infinity AI Forge Hackathon (Challenge 06).

Core Features:

  • Instant PDF & text note parsing via PDF.js.
  • Gemma 4 model integration (gemma-4-26b-a4b-it).
  • 3D interactive flashcards & practice quizzes.
  • Anki CSV & structured JSON schema exports.
